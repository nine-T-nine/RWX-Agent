MICRO / FIXED SCENARIOS独立评分 · 不与完整对局混榜

微操 CASE 评分

每个 CASE 独立按 100 分起扣，不属于 v1/v2 完整对局体系。环境截图来自固定 task + seed 的真实游戏窗口，用来快速理解任务空间；不同 task 或 seed 的具体布局会变化。

GAPS / MATERIAL材料不足 · 不计分

没有进入排名的材料

把“打了但材料不够”与“根本没打成”分开记录，避免用猜测补分。重放分叉的局（4P 归档）与回放未完成的局都在这里，写明原因，不进入任何均分。
