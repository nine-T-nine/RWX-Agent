03 / FULL-MATCH SCORING完整对局 · v2 公式

完整对局怎么扣分

Stage1-v2 衡量交互节奏，Stage3 从四类严重失误扣分。所有当前参数以 evaluate/config.json 为唯一账本；未在设计中确定的值明确标记 provisional。

S1-v2 = 100 − 启动 / 回合延迟 / 空窗扣分 S3 = max(0, 100 − 四项扣分) total-v2 = 0.4 × S1-v2 + 0.6 × S3

04 / MICRO CASES固定场景 · 独立评分

微操 CASE 评分

每个 CASE 独立按 100 分起扣，不与完整对局混榜。环境截图来自固定 task + seed 的真实游戏窗口，用来快速理解任务空间；不同 task 或 seed 的具体布局会变化。

05 / MATERIAL GAPS材料不足 · 不计分

没有进入排名的材料

把“打了但材料不够”与“根本没打成”分开记录，避免用猜测补分。重放分叉的局（4P 归档）与回放未完成的局都在这里，写明原因，不进入任何均分。
