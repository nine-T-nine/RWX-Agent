评测结果

这里列出目前所有完成过的 RWX 对局：当前标准里同图、同工具的对局可以横向比较，归档账本只作历史参考，材料不足的对局单独列出、不计分。

total-v1 = stage1-v2 × 0.4 + stage2-v2 × 0.6。

01 / TOOL COMPARISON同一模型 · 同一地图 · 三种接口

换了工具，分数变了吗？

三局都由 deepseek-v4.1-flash（推理强度 high）在 Ice Island (2p) 对阵 Hard AI、x2 收入下完成。唯一的变量名义上是工具接口：原生 shell、MCP 第二版、MCP 第三版。

一句话结论：工具接口没有改变胜负——三局全败；tool3 领先的 12.7 分几乎全部来自第二阶段的资源与工厂利用率，而第一阶段它其实不如没有 MCP 的 tool1。

三局的可比指标（均为同一地图、同一对手、同一经济倍率；分数越高越好，扣分类指标越低越好）

1. 三局都输了，分数差异只在过程指标上

tool1 与 tool3 在主基地失守后主动投降，tool2 在 12:22 被摧毁。评分体系里没有胜负项，所以“分数更高”只说明过程更规整，不说明更接近赢。要判断强弱，必须在同一工具下重复多局。

2. 没有 MCP 的 tool1，第一阶段反而最高（70.5）

它的首个行动指令扣分最多（13.5），但其余项最多只扣 4.7 分——原生工具一次 pwsh 可以批量下发多条命令，动作连续；第二阶段 65.8 也不算差，主要扣在资金闲置 7 分、工厂空闲 4.5 分。

3. tool2 是三局最低（61.6），MCP 并没有自动变快

它的决策周期 20.0 秒为三者最慢，行动指令只有 58 条，偷袭损失扣分 11.59 为三者最高。工具总耗时 286 秒，是 tool1（125 秒）的 2.3 倍：把“观察 + 下令”打包成一次调用后，每一步都要等桥接返回，1x 实时里反而压缩了可用决策次数。

4. tool3 的领先来自第二阶段（79.0）

资金闲置 0 分、工厂空闲 0 分、偷袭损失 1.03 分，是它把资金持续转成建筑与部队的直接结果；代价是第一阶段只有 67.2——底层生产指令 7.46 条/分触发满额扣分（6/6），行动被拆成 884 次查询对 176 次行动。

5. 不能把 +12.7 归因给“MCP 更好”

tool3 与 tool2 的差别不只是接口：提示词增加了路径与暂停说明，并补上“游戏秒 / 收入单位”的口径，桥接摘要也加了 /s 游戏秒 后缀；同为无 MCP 的两局基线相差 4.7 分（67.67 与 62.98），而每臂只有 1 局，12.7 分的差距仍无法与提示词变化、局间波动分开。

02 / CURRENT STANDARD当前标准 · 可横向比较

当前标准下的全部对局

以下对局都带有完整证据链（回放、实时遥测、伤害 HP 字段），版本为 stage1-v2 / stage2-v2，综合分 total-v1。评测者标注为“模型 + 工具 + 推理强度”。其中 2026-11-04 新增的对局只作单局记录：Fire Bridge (2p) 换了地图，Ice Island 的 push 局换了事件交付方式（L2 harness），火山 (8p) 的三局则是同队四智能体共控一个玩家、对手配置也与其他局不同，都不参与上面的三接口对比。

按综合分排序；结局一列是游戏内结果，不参与计分。
03 / FULL-MATCH SCORING完整对局 · 两阶段扣分表

完整对局怎么扣分

第一、第二阶段都从 100 分起扣；每项先按自己的上限封顶，再求和。扣分项与说明保持稳定，公式和参数集中在独立数据文件中，便于后续调整。

S1 = max(0, 100 − Σ 第一阶段扣分) S2 = max(0, 100 − Σ 第二阶段扣分) 总分 = 0.4 × S1 + 0.6 × S2

04 / MICRO CASES固定场景 · 独立评分

微操 CASE 评分

每个 CASE 独立按 100 分起扣，不与完整对局混榜。环境截图来自固定 task + seed 的真实游戏窗口，用来快速理解任务空间；不同 task 或 seed 的具体布局会变化。

05 / DEDUCTION BREAKDOWN两个阶段 · 每一分扣在哪里

逐项扣分

两个阶段都是 100 分起扣：第一阶段 12 项、第二阶段按 6 类事件封顶。表内数字是实际扣分与该项上限；达到上限标“封顶”，原始累计超过上限时附“原始”。

三局对比组（同模型、同地图）；2026-11-03 起偷袭上限 35、单次上限 18、γ 3。
06 / ARCHIVE历史账本 · 不与当前标准混榜

归档对局

这些对局的材料在 2026-11-02 至 03 的整备中归档为 _old：当时没有保留完整的伤害 / HP 证据，无法按当前口径复算第二阶段的偷袭与损失扣分。分数只能代表当时的材料，模型与工具归属按目录名记录，未逐局核验。

仅第一阶段 / 第二阶段分，不含综合分。
