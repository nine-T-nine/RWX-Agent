# 原版测试脚本功能说明

本目录保留 6 个规则驱动的 JavaScript 辅助脚本，主要用于单位微操、建造、生产和维修。

这些脚本依赖原宿主的 Java 桥接接口，由宿主调用 `init()` 和 `onTick(tick)`。接入当前 RWX 的 CLI 工具或 Java 自定义 AI 前仍需适配；统一为 `.js` 后缀不代表可以直接运行。

| 文件 | 功能 |
| --- | --- |
| [重拦缠斗.js](重拦缠斗.js) | 围绕锁定目标攻击、绕飞和后撤；目标死亡或新目标明显更近时才切换，减少频繁换目标。 |
| [重拦阵型.js](重拦阵型.js) | 分配输出和引火角色，结合集火检测、残血程度执行绕飞、护卫和撤退，并限制重复发令。 |
| [建造者协防.js](建造者协防.js) | 配合机枪机甲对抗猛犸，在双方之间尝试建造炮塔；也包含通过附近建造尝试脱困及机甲死亡后建造者撤退的流程。 |
| [自动补兵.js](自动补兵.js) | 记住工厂生产队列最后一种单位，队列清空后继续生产，并检查资金、避免重复下单。 |
| [自动建造.js](自动建造.js) | 开局前 30 秒尝试补足两个建造者，并安排附近建矿；记录到两个建造者各完成过一次建矿后停止。 |
| [智能修复湾.js](智能修复湾.js) | 优先维修受损机枪机甲；没有受损机枪时再维修其他单位，按血量百分比和已有分配选择目标。 |

重拦系列是不同战术分支，使用时应为同一单位选择一种控制策略，避免多个脚本互相覆盖指令。部分脚本还依赖原宿主的单位策略勾选功能。
