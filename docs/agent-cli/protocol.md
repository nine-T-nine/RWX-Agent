# RWX 本机 agent CLI 协议（阶段一）

## 传输

TCP，地址 `127.0.0.1:<agent-port>`。每条 UTF-8 文本命令以换行结束，服务端每条命令返回一行文本。使用 `rwxctl.py`，无需自行维护连接。

## 查询命令

| 命令 | 返回 | 说明 |
| --- | --- | --- |
| `ping` | `pong` | 连通性检查 |
| `brief` | JSON | tick、地图、玩家队伍、资源、我方数量、可见敌人数量 |
| `units own` | JSON 数组 | 可控制的本方活单位 |
| `units enemy` | JSON 数组 | 当前可见敌方活单位 |
| `units all` | JSON 对象 | 上述两项的组合 |

每个单位行包含 `id`、`type`、`x`、`y`、`hp` 与 `maxHp`。

## 命令

| 命令 | 示例 | 效果 |
| --- | --- | --- |
| `move IDS X Y` | `move 42,43 900 650` | 普通移动 |
| `attack-move IDS X Y` | `attack-move 42,43 900 650` | 攻击移动 |
| `attack IDS TARGET_ID` | `attack 42,43 91` | 攻击可见目标 |
| `stop IDS` | `stop 42,43` | 清除当前命令 |

`IDS` 是逗号分隔的单位 object id；命令只能操作本地玩家队伍的可控制活单位。成功时返回 `ok`，失败时以 `error:` 开头且不提交命令。

## 边界

端点仅在活跃单机战斗中接受语义命令。多人游戏、回放、非活动战局、其他队伍单位与失去视野的攻击目标都会被拒绝。端口只绑定回环地址，不能远程访问。
