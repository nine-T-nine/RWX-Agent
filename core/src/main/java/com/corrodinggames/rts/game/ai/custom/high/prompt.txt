# AI-high 规格（可执行版）

> 本文件是 AI-high（`CustomHighAiStrategy`）的唯一规格来源。所有"距离/范围/方向"都不再写在自然语言里，
> 统一收敛到 §5「距离定义表」，用记号引用；表中每一项都标注了**当前实现值**与**单位**，待确认项标 `⚠️Dn`。

## 0. 口径与记号

| 记号 | 含义 | 引擎来源 |
|---|---|---|
| `T` | 游戏时长（分钟） | `GameEngine.gameTimeMillis / 60000` |
| `C` | 资金 | `AIController.credits` |
| `I` | 每秒收入 | `PlayerTeam.getScaledIncomeRate()` |
| `N(x)` | 我方 x 数量（**含工厂队列**） | `AiUnits.count` |
| `E(x)` | 敌方 x 的记忆数量（见过就记、死亡减一） | `AiEnemyIntel` |
| `L(x)` | 我方 x 的等级（1/2/3） | `getUpgradeLevel()` |

- 时间单位：秒/分钟；AI 节拍按 delta 归一（60 帧 = 1 秒），**与 fps 无关**。
- 距离单位：世界单位；`1 格 = 20 世界单位`（见 `docs/尺寸与距离单位.md`）。
- "有 N 级 X" = 存在 `L(X) = N` 的设施；"否则有 1 级 X" = 没有 2 级 X 但有 1 级 X。

### 3.1 只接管选址的 5 类建筑
其余建筑（工厂、指挥中心、提取器、机甲工厂…）**完全沿用原版**：选型来自原版打分，选址与选人来自原版 `BaseZone.tryBuildUnit`。

| # | 建筑 | 选型 | 选址规则 |
|---|---|---|---|
| 22 | 修复湾 | 原版打分（分数覆盖为 `0.1`） | 覆盖半径 `R_repair` 内满足「≥1 矿 ∧ ≥3 炮台」或「≥6 炮台」；找不到位置就不建 |
| 23 | 极光防御 | 原版打分 | 必须落在前线；覆盖半径 `R_laser` 内最多 1 个（敌有机枪机甲时不限） |
| 24 | 资源制造仪 | 原版打分 | `C > 2000 ∧ I > 100`，且落在指挥中心覆盖 `R_cc` 内 **或** 满足 `D_back`（前线后 > 50 格 ∨ 距指挥中心 < 70 格）；优先紧贴已有制造仪 |

| 26 | 1 级普通炮塔 | 原版打分 | 敌方陆地可达的我方矿脉（到前线为止）、面向敌方一侧、矿覆盖 `R_ore` 内；每处 `0.5` 概率、上限 2（前线 `0.05` 概率加到 5） |

### 3.2 防空炮台三条规则（按优先级）

| 规则 | 条件 | 位置 |
|---|---|---|
| ① 前线炮塔后方 | 防空 : 炮台 `< 1:3`（即 `3·N(AA) < N(炮台)`） | 随机挑一个前线炮台，在其背离敌方方向 `±45°`、距离 `D_aa_min ~ D_aa_max` 内取合法点 |
| ② 野生矿 | 该矿距指挥中心 `> D_wild`、周围 `R_prod` 内无我方生产建筑、矿覆盖内 AA `< 3` | 矿覆盖 `R_ore` 内随机取点 |
| ③ 渡口 | 我方到敌方路线上的液体交点、靠我方一侧、距我方指挥中心 `≤ D_cross`、该处 AA 数 `< 1`；`0.01` 概率 | 渡口周围 `R_cross` 内随机取点 |

### 5.1 前线与我方一侧（D5）

**前线 = 我方最外侧防御线**：取我方所有"有攻击距离的建筑"（含防空/极光/普通炮台，排除指挥中心）中，
**到敌方指挥中心步数最小**的那个值 `F`（单位：格）；`F` 那条线就是我方前线。

| 判定 | 定义 | 退化情形 |
|---|---|---|
| `isFrontline(x, y, band)` | `\|到敌方步数 − F\| ≤ band` | 没有防御建筑 → 用任意我方建筑；再没有 → 退回"双方指挥中心步数差 ≤ band" |
| `isOurSide(x, y)`（"到前线为止"） | `到敌方步数 ≥ F` | 同上退回"我方比敌方更近" |
| `depthBehindFrontline(x, y)` | `到敌方步数 − F`（越大越靠后） | 同上退回 `敌方步数 − 我方步数` |

### 5.2 方向类定义

| 记号 | 含义 | 实现 |
|---|---|---|
| "面向敌方" | 矿脉炮塔的取点方向 | 朝敌方指挥中心方向 `±90°` 半圆内随机取点 |
| "炮台后方" | 防空炮台相对炮台的方位 | 以"炮台→最近敌人"的反方向为 0°，`±45°` |
| "靠我方一边" | 渡口归属 | 该点到**我方**指挥中心距离 < 到**敌方**指挥中心距离 |
| "敌人陆地可达" | 矿脉炮塔/渡口的前提 | 敌方指挥中心的 LAND 距离场可达该点 |
