# Autopilot 策略意图（可实现规格）

## 0. 记号与框架

| 记号 | 含义 |
|---|---|
| `I` | 每秒收入 = `PlayerTeam.getScaledIncomeRate()` |
| `C` | 资金 = `AiContext.credits()` |
| `T` | 游戏时长（分钟）= `GameEngine.gameTimeMillis / 60000` |
| `N(x)` | 我方 x 的数量（含工厂队列） |
| `E(x)` | 敌方 x 的记忆数量 = 非迷雾区可见累计 − 已知摧毁 |
| `L(x)` | 我方 x 的最高等级（1/2/3） |
| 时间 | 单位为秒；`60 帧 = 1 s`；一轮 = `250 帧 ≈ 4.2 s` |

- 〔模式〕同一时刻只允许一个；〔常驻〕可与模式并行。
- 主模式阶梯（单向升，回退需条件持续 60 s）：`S1(I<80) → S2(I≥80) → S4(I≥100)`，优先级 `S4 > S2 > S1`。
- `S7/S8` 按时间窗切换；`S5` 独立门控；`S3/S6/S9` 常驻。主模式缺钱时 `S3/S5/S7/S8` 让路。

---

## S1 低收入爆兵〔模式〕
- 条件：`I < 80`
- 行为：
  1. `N(landFactory) < 5` → 补建 1 级陆军工厂至 5 座（原话 3~5）
  2. 其余产能全造 `tank`（350），默认囤积不出击
  3. 例外：`∃ 我方建筑/炮塔/建造者 : hp < maxHp` ∨ `BaseZone.isUnderAttack()` → 派 `tank` 护卫
  4. `N(tank) > 10` → 放行全部 `tank` 进攻（目标与编队沿用原版）
- 时长：保持 `≥ 120`，每 `60` 重评估；退出 `I ≥ 80` 持续 `60` 或已放行

## S2 中期主力〔模式〕
- 条件：`I ≥ 80`
- 行为：
  1. `N(landFactory) ≥ 2` ∧ 全部 `L(landFactory) = 2`
  2. 造 `heavyTank`(800) / `plasmaTank`(1000)，约束 `1/5 ≤ N(plasmaTank)/N(heavyTank) ≤ 3/5`
- 时长：保持 `≥ 180`，每 `60` 重评估；退出 `I < 80` 持续 `60`

## S4 机甲线〔模式〕
- 条件：`I ≥ 100`
- 行为：
  1. 建 `mechFactory` 至 `N = 2`，其中恰 1 座升 `mechFactoryT2`
  2. 持续造 `mechMinigun`(5000)；每新增 1 个 → 发起 1 次进攻
  3. 每次进攻的防空护卫数 `k = min{ k ∈ [1,5] : roll(0.85) 命中 }`（全不中取 5）；
     `N(mechMissile) < k` → 补造 `mechMissile`(900)
- 时长：保持 `≥ 240`，每 `60` 重评估；退出 `I < 100` 持续 `60`

## S5 资源制造仪〔投资·独立门控〕
- 条件：`C > 2000` ∧ 最近 `300 s` 内无我方损失（炮塔 ∨ 矿脉 ∨ 生产建筑）
- 行为：
  1. `∃ fabricator : L < 3` → 升级该制造仪 1 级（`T1→T2` ∨ `T2→T3`）
  2. 否则建 `fabricatorT1`(2200)，位置 = 指挥中心覆盖内 ∨ 我方后方；优先紧贴已有制造仪
- 时长：动手后保持 `≥ 60`，每 `60` 重评估；损失后冷却 `300`

## S7 海军窗口〔模式〕
- 条件：`I > 70` ∧ `T < 20` ∧ `N(seaFactory) ≥ 1`
- 行为：始终保持 `1` 艘 `battleShip`(1500) 在途/在场，不叠第二艘；造好即进攻（目标沿用原版）
- 时长：保持 `≥ 90`，每 `60` 重评估；退出 `T ≥ 20`

## S8 后期投资〔模式〕
- 条件：`T > 20` ∧ `I > 120` ∧ (`无生产建筑损失` ∨ `炮台损失 < 3`)，窗口 `20 min`
- 行为：每轮 `roll(0.5)` → 升级 1 条矿脉（`T1→T2→T3→T3_overclocked`）；
  否则升级 1 座制造仪（`T1→T2→T3`）；若 `∀ fabricator : L = 3` → 新建 1 座
- 时长：保持 `≥ 120`，每轮（250 帧）1 个动作；退出 `I < 120` 持续 `60` 或损失超阈值

## S3 矿脉超频〔常驻〕
- 条件：无
- 行为：每轮推进 1 条矿脉链 `extractorT1 → T2 → T3 → T3_overclocked`；
  候选顺序 = 等级降序（先顶满一条）；`C > 2500` 才动手
- 时长：每轮 1 个动作；每 `300` 重排候选

## S6 空军线〔常驻〕
- 条件：无
- 行为：
  1. `N(airFactory) < 2` → 补建；且全部 `L(airFactory) = 2`
  2. 造 `heavyInterceptor`(1200) / `gunShip`(800)，约束 `1/4 ≤ N(heavyInterceptor)/N(gunShip) ≤ 3/5`
  3. 约束 `N(air) ≥ Σ w·E(x)`，权重 `w`：`c_interceptor 0.5`、`heavyInterceptor 1`、`amphibiousJet 2`、`missileAirship 2.5`
- 时长：每轮最多 1 架；每 `60` 重算 `Σ w·E(x)` 与比例；比例纠偏容差 `±1` 架

## S9 前线加工〔常驻〕
- 条件：无
- 行为：
  1. 进攻兵限流：距上次生产陆地攻击单位 `≥ 240` 才允许再出 1 个
  2. 1 级炮台升级分派：`roll(0.8) → c_turret_t2_gun`，否则 `categorical(喷火 c_turret_t2_flame 0.2, 电击 c_turret_t1_lightning 0.5, 火炮 c_turret_t1_artillery 0.3)`
  3. 大件：`I > 120 ∧ roll(0.05)` → 攒 `c_turret_t3_gun ∨ c_turret_t2_artillery ∨ c_turret_t2_lightning`，**该轮不产生任何其它花费**
  4. 否则新建 1 个 `c_turret_t1`(500)
  5. 防空：`L < 2` → 升 `c_antiAirTurretT2`；否则新建 `c_antiAirTurret`；约束 `1/3 ≤ N(AA)/N(陆炮) ≤ 1`；
     且 AA 必须位于炮台后方（45° 扇区、≤ 5 格）
  6. 选址：逐个前线陆炮 → 在其射程内轮询 → 命中一个则 `roll(0.5)` 进入该分支并停止轮询
- 时长：每轮 1 个动作；进攻兵冷却 `240`

## 时长汇总

| 策略 | 类型 | 最短保持 | 重评估 | 退出条件 |
|---|---|---|---|---|
| S1 | 模式 | 120 | 60 | `I ≥ 80` × 60 ∨ 已放行 |
| S2 | 模式 | 180 | 60 | `I < 80` × 60 |
| S3 | 常驻 | — | 250 帧 | 无未超频矿脉 |
| S4 | 模式 | 240 | 60 | `I < 100` × 60 |
| S5 | 投资 | 60 | 60 | 损失后冷却 300 |
| S6 | 常驻 | — | 250 帧 / 60 | 无 |
| S7 | 模式 | 90 | 60 | `T ≥ 20` |
| S8 | 模式 | 120 | 250 帧 | `I < 120` × 60 ∨ 损失超阈值 |
| S9 | 常驻 | — | 250 帧 | 无（进攻兵冷却 240） |

## 复用原版
运输、核弹与反核、编队/进攻/拆除目标选择，全部沿用原版；本规格只接管「生产、升级、建筑放置」。
