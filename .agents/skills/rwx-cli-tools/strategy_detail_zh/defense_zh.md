# 防御与兵种反制

> 仅在防御部署、遭受攻击或准备反炮兵/防空时阅读。优先使用已有兵力解决即时问题：新建炮塔和升级不能立刻转化为战斗力。

## 1. 先判断威胁

| 敌方情况 | 防御重点 | 常见失误 |
|---|---|---|
| 低血量陆军集群 | 喷火炮塔、范围伤害、火炮 | 只增加普通低级炮塔数量 |
| 机甲突击 | 电击塔、T2 电击塔、火炮 | 忽略护盾穿透和机甲的山地机动 |
| 远程火炮 | 激光防御塔、反炮兵火力、重新部署 | 在敌火炮射程内持续集结密集部队 |
| 空军突袭 | T2 防空、防空机甲、拦截机 | 把 T1 防空当成完整防空体系 |
| 高级空军密集突击 | T3 防空、高射炮、AA 战机等 | 防空火力零散分布，无法快速击落目标 |

处理顺序：**确认受到威胁的资产 → 调动现成反制力量 → 判断是否需要补产/建塔 → 观察战斗结果**。在明显守不住时，考虑撤出高价值机动部队并建立下一道防线。

## 2. 陆地炮塔

| 单位/升级 | 经验用途 | 约束 |
|---|---|---|
| T2 机枪 | 通用守家主力 | 不能替代所有专门防御 |
| T3 机枪 | 范围广、攻速快，单座就能提供强火力 | 约 11000，前期一般不使用 |
| 喷火器 | 克制普通机甲、Tank、悬浮坦克等低血量集群 | 约 500+700，射程偏短但血量较高 |
| 电击塔 | 克制机甲、穿透护盾 | 攻速慢，不宜单独面对海量目标 |
| T2 电击塔 | 强力克制高级机甲 | 昂贵，按实际威胁升级 |
| 火炮炮塔 | 远距离陆地压制 | 升级约需 1600，前期通常不优先 |
| T2 火炮炮塔 | 极远射程，适合阵地推进与远程压制 | 价格高，前期通常不使用 |

炮塔在 RWX 中不是可有可无的设施；成熟防线能抗衡大量进攻部队。但不能只靠单一种炮塔应对全部敌情。

## 3. 防空选择

| 单位/升级 | 经验用途 | 成本/限制 |
|---|---|---|
| T1 防空炮塔 | 最基础的点防御 | 约 600；单独防守较弱 |
| T2 防空炮塔 | 常规阵地防空优先选择 | 约 600+1200 |
| T3 防空炮塔 | 高级大范围防空 | 约 12000，昂贵 |
| 高射炮 | 对空群体伤害高 | 约 4000，射程略小 |
| 防空机甲 | 机动、性价比高的范围防空 | 血量中等，适合随主力行动 |
| 重型拦截机 | 高速、快攻速机动防空 | 避免无支援冲入敌方防空区 |

不必给每个角落都建昂贵防空。重点覆盖指挥中心、经济区、关键工厂和预计遭到空袭的路线。

## 4. 辅助防御与防守火炮

- **修复湾（约 1500）**：适合修复高血量高级单位；有炮塔前线时尽量覆盖前沿炮塔。经济紧张时通常最多一个，且须有能持续受益的单位。
- **激光防御塔**：常用于抵御敌军火炮等发射物攻击；升级 T2 约需 2000。它并非对所有伤害都有效的万能屏障。
- **重型火炮**：T2 陆军工厂，约 2000+；适合远程防御、压制敌军地面推进。
- **火炮机甲**：T1 机甲工厂，约 1700；适合机动火炮与山地地图。

## 5. 防线建设原则

1. 优先守住**指挥中心、主要矿区、关键生产建筑**，而非平均铺满地图。
2. 重要炮塔位置尽量形成交叉火力，并关注维修和反炮兵保护。
3. 防线前移时先建立可维持的火力覆盖，再逐步推进；不要让建造者无保护地深入敌阵。
4. 如果敌方主要依靠空军，及时减少无关的陆地炮塔支出；反之亦然。
5. 战场已证明防线失效时，要改变反制手段，而不是机械地重复同一种建造方案。
