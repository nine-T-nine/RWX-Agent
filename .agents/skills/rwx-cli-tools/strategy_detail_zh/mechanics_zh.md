# 游戏机制与单位使用边界

> 本文件是补充说明。遇到机制疑问、准备使用非常规单位或高成本战术时再阅读；不要因此推迟紧急作战。

## 1. 关键机制

| 机制 | 决策含义 |
|---|---|
| 指挥中心：自带 +18 收入，血量高、可对空，火力中等但攻速慢 | 能独立抵御较弱骚扰，但不能假设它能挡住成群部队或专门克制单位 |
| 工厂下单立即扣钱 | 生产前检查余额与其他紧急支出 |
| 护盾通常会自行恢复；电击可以穿透护盾 | 对高护盾机甲可优先考虑电击武器 |
| 多数机甲有山地通行优势 | 利用复杂地形；同时注意火炮和电击威胁 |
| 拦截机专门对付空军 | 用于机动防空，避免拿它执行无关的地面强攻 |
| 炮塔防线有很高的战斗力上限 | 不要低估阵地战；也不要无条件把全部经济投给固定设施 |
| RWX 常见人海战术、经济扩张、马奇诺防线、核弹博弈 | 根据经济倍率、地图和敌情选择战术，不能套用固定开局 |
| 局势变化快 | 指令执行后仍须关注结果；战场异常应优先处理 |

## 2. 人类对局通常不优先的单位

| 单位 | 经验判断 | 可以例外的情况 |
|---|---|---|
| 普通直升机 | 人类对局很少选用 | 存在明确低成本用途 |
| 轰炸机 | 通常后期才投入，用于轰炸坚固阵地 | 经济宽裕且目标固定、价值足够高 |
| 屏蔽气垫坦克（实验单位，约 21000） | 太昂贵，常规对局不实用 | 极富裕的持久战 |
| 特斯拉机甲（T2 机甲工厂） | 容易死亡，通常不优先 | 有明确电击克制目标且可保护它 |
| 普通潜艇（约 800） | 耐久偏弱，人类少用 | 水下路线具有明确战术收益 |

“很少用”不是“禁止用”。Agent 可以凭更好的信息或多部队控制能力发挥这些单位的价值。

## 3. 使用这些经验时的边界

- 文中价格、科技来源、克制关系与“常用”程度均来自经验整理；**以当前实际游戏状态、MOD 配置和可用动作为准**。
- 不要将“某单位可以打某目标”理解为“不计数量、位置和时机必胜”。
- 不要将“10+ 单位”“5+ 战列舰”“2–3 座矿”等经验数量当作严格触发阈值。
- 如果现有状态与经验冲突，优先相信当前状态并修正打法。
- 本文件不定义 Agent 如何查询、等待、订阅事件或发送命令，这些属于通信与工具文档。
