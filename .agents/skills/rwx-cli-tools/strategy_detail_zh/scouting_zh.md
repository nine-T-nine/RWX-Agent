# 侦查与情报有效性

> 侦查的目标是**减少具体行动的不确定性**，不是把全图永久点亮。当前可见事实优先于旧情报；失去视野不等于敌军消失。

## 1. 什么情况需要侦查

| 情况 | 需要确认的内容 | 确认后行动 |
|---|---|---|
| 准备大规模正面进攻 | 火炮、T2/T3 防线、范围伤害、防空、兵力位置 | 选择突破方向与反制编队 |
| 上次进攻被瞬间击溃 | 哪种敌军造成主要损失，位置是否改变 | 改战术，而非重复派兵 |
| 大量野生矿脉无人可见 | 哪些矿被敌军占据，是否有暴露的建造者 | 扩张、骚扰或阻断 |
| 自家据点遇袭但敌人不在视野 | 威胁来源、行进路线、兵种类型 | 防守、追击或建立下一道防线 |
| 准备空降/跨海进攻 | 目标防空与海上/空中拦截 | 选择安全路线与进攻时机 |

## 2. 常用侦查单位与设施

- **间谍无人机（约 1500）**：T2 空军基地生产，血量较高，适合专职侦查。
- **瞭望塔 T1（约 1500）**：扩展固定视野，常部署在前线稍后方。
- **瞭望塔 T2（追加约 2000）**：适合覆盖更大范围迷雾；普通建造者不能直接建造，须确认实际建造方式。
- **拦截机、重型拦截机**：高速，可临时快速确认目标，但要避开敌方有效防空。
- **其他高速空中单位**：可用于侦查；是否值得牺牲取决于其成本和侦查收益。

## 3. 战争迷雾判断

将信息分成三种：

1. **当前可见**：可直接用作战术依据，但仍会随战斗变化。
2. **最后已知**：单位可能还在附近，但其位置和数量已经不确定。
3. **未侦查**：不能因没有敌军标记就推断区域安全。

对于最后已知的火炮、防空、敌军主力，应在相关战术中保留威胁假设；如果该假设决定大额投资或进攻成败，优先再次确认。

## 4. 避免侦查拖慢决策

- 已有足够证据支持低风险行动时，直接行动。
- 高风险进攻需要侦查，但也不应无限等待完美地图信息。
- 重要新情报必须能改变命令或战术，否则不要频繁重复相同侦查。
- 侦查单位尤其是高速飞机，不能误当作可以无限牺牲的免费工具。
