# 地形、路线与战略据点

> 地形决定可达性、火力覆盖和进攻节奏。先确认单位能否抵达目标，再比较路线是否有利。

## 1. 山地

- 山地面积大且路径复杂时，能够越过山崖的**火炮机甲、机枪机甲等机甲单位**通常更灵活。
- 不要把普通坦克的通行路径默认套用到机甲，反之亦然。
- 可以利用山地进行绕侧、骚扰与越障突破，但要注意敌方电击与火炮反制。

## 2. 陆地不可达矿脉

- 有些矿位于海岛或与本土不连通的地带；普通陆军、陆地建造者不一定能直接到达。
- 可考虑**海上建造者**、运输或其他可达手段扩张。
- 即使己方暂不占领，也应警惕敌方据此形成易守难攻的经济据点。
- 行进失败先核实地形和单位移动类型，不要原样重复无效命令。

## 3. 岛屿与海岸线

- 沿岸矿脉与前沿海岛适合海上建造者建设据点。
- 海军战列舰可利用射程压制低级沿岸阵地，但自身不对空。
- 建立跨海据点时要同时评估防空、反舰、施工时间和后续增援路线。

## 4. 孤立岩浆岛屿

三种典型方案：

1. **沿岸控场**：火炮对轰、T3 机枪等远程压制，取得滩头控制后陆军登陆。
2. **空军强攻**：敌方防空不足、己方空军数量足够时集中突袭。
3. **强行空降**：运输/飞行堡垒携陆军突入，冒险直接占点。

根据敌方防空、岸防和水面控制能力选择；不要默认单一方式总是可行。

## 5. 进攻路线与抵达时间

- **高速单位**：拦截机、重型拦截机、运输机、侦察无人机往往比陆地主力快得多。
- 混编长途攻击时，高速单位可能先进入敌火力圈而遭单独击破。需要同时攻击时，可先在安全地点集结。
- 部队进入敌火炮射程前，优先判断是否可绕过、分散或远程反制，而不是密集直线推进。
- 防线推进需要可持续补给和施工保护，不宜孤立地把建造者送至敌军射程内。
