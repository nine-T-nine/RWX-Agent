# 进攻与编队策略

> 人类对局中的经典打法仅供参考。Agent 具备同时管理混合部队的潜力，但应依据敌方弱点选择组合，不必为了混编而混编。

## 1. 进攻前的四个判断

1. **目标**：要摧毁什么？指挥中心、矿区、防御塔、工厂还是敌方主力？
2. **克制**：目标周围有哪些能有效攻击我方主力的单位？特别注意火炮、范围伤害、防空、电击塔。
3. **抵达**：路线是否可达？高速单位会不会先到并被逐个击破？
4. **交换**：即使能打赢，代价是否值得？是否存在绕侧、佯攻或更容易的目标？

情报不全不必无限等待，但**经历明显的兵种克制失败后，不得在相同条件下重复冲锋**。

## 2. 陆军战术

### 重型坦克 + 等离子坦克

- 来自 T2 陆军工厂，单价相对实惠，适合形成中级地面集团军。
- 常见于人海战术，对一般地面战线有效。
- 主要弱点是敌方火炮、实验坦克和强范围火力；对炮阵不要密集送兵。

### 机枪机甲

- T2 机甲工厂（约 1000+5000）生产，单位约 4500+。
- 灵活、攻速高、能无视山崖；可以压制许多中低级单位及较弱的 T1/T2 炮塔。
- **不对空**：通常配至少 2 台防空机甲进行护卫（具体数量按敌情调整）。
- 害怕电击塔、火炮、猛犸坦克。

### 钢铁洪流与混编

由重型坦克、等离子坦克、猛犸坦克、机枪机甲、喷火机甲，以及防空机甲/重型防空机甲/防空导弹坦克等组成。

- 只生产与当前威胁相关的兵种：主力输出 + 防空 + 必要的远程压制或护盾处理。
- 混编的价值在于**补齐弱点**，不是堆砌种类。
- **重型气垫坦克**：中级悬浮单位，属性较均衡但速度较慢；水陆特殊路线可能有用。

## 3. 空军战术

| 单位 | 适用打法 | 主要风险 |
|---|---|---|
| 武装直升机（约 800） | T2 空军工厂量产，快速打击防空不足的基地与建筑 | 血量低，怕拦截机、防空机甲、T2/T3 防空炮塔 |
| 两栖喷射机 | 电击伤害、血量较高；可潜水攻击水面部队，争夺海权 | 应核实水面/空中敌情 |
| 侦查无人机 | 高速且较耐打，可侦查；必要时替高价值空军吸收部分防空火力 | 无攻击力，不宜无收益地牺牲 |
| 导弹飞艇 | 后期高血量重型空中进攻，适合资金雄厚时成群突破 | 投入大，注意集中防空 |
| AA 战机 | 后期高强度空中反制，能对付高级敌机 | 需有足够经济与明确防空需求 |
| 飞行堡垒 | 空中前沿据点、生产中级陆军，或运兵深入敌后实施空降 | 怕拦截机及 AA 战机，需确认航线安全 |

人类在富裕的超后期可能使用数十架导弹飞艇或 AA 战机，但那不是常规编队数量要求。

## 4. 海军与沿岸进攻

**战列舰（约 1500）**是实用的早中期海军单位：

- 射程略大于 T2 机枪，可攻击低级沿岸阵地。
- 条件合适时，5 艘以上可拿下孤立指挥中心。
- **不对空**：需要时由拦截机或导弹舰提供防空/反潜支援。

## 5. 速攻、骚扰与建造者推进

| 战术单位 | 典型用途 | 限制 |
|---|---|---|
| 普通机甲（10+） | 前期集群速攻 | 害怕炮塔和范围伤害 |
| Tank（约 350/个） | 廉价人海、袭击薄弱位置 | 面对火炮容易集中损失 |
| 轻型微机（约 250/个） | T1 空军基地生产，偷袭野外建造者 | 低血量，不适合攻坚 |
| 悬浮坦克（约 450/个） | 前期突袭仅有 T1 炮塔的阵地 | 不能盲打升级防线 |
| 建造者（约 500/个） | 集群快速造炮塔、激光防御塔，搭建前推阵地甚至拿下孤立指挥中心 | 自身脆弱，需火力掩护 |

“10+”仅是人类经验中的常见有效规模，**不是达到数字就必然能赢**。

## 6. 目标优先级与实时协同

- **地面进攻**：优先移除直接威胁地面主力的火炮/炮塔；时间紧迫时可绕过纯防空设施。
- **空中进攻**：先考虑防空与拦截机；时间紧迫时可无视不能对空的地面炮塔。
- **速攻**：先处理能反击的关键单位或建筑，或在损失可接受时直接攻击胜利目标。
- **经济战**：矿脉、暴露的建造者和工厂，有时比敌方主力更有价值。
- **长途进攻**：拦截机、重型拦截机、运输机、无人机通常比陆军快；需要协同时，可先集结再冲锋。
- **失利后**：改变兵种、目标、路线、时机或侦查方式；不要按原计划继续损失部队。

其他通常不优先生产的单位与原因见 [mechanics.md](mechanics.md)。
