# 经济发展与扩张

> 对经济的判断要同时看：**经济倍率、当前收入、余额、矿脉数量/等级、工厂产能、威胁与下一笔重要支出**。不要只看余额或收入之一。

## 1. 经济倍率

| 倍率 | 常见体验 | 发展建议 |
|---|---|---|
| x1 | 很穷 | 用廉价有效单位保护矿区，谨慎投资高级科技 |
| x1.5 | 偏紧 | 优先保证基础战力与扩张，不要同时开太多昂贵项目 |
| x2 及以上 | 相对流畅 | 可更积极升级矿、混合编队及长期发展 |

## 2. 根据收入判断投入能力

| 每秒收入 | 经验档位 | 适合考虑的生产 |
|---|---|---|
| ≤50/s | 穷 | T1 Tank、少量重型/等离子坦克、普通机甲、防空机甲、火炮机甲、拦截机与武装直升机、战列舰 |
| 50–100/s | 开局正常 | 一般可选择单价约 2000 以内的单位 |
| 100–200/s | 小康 | 多数中高级单位，组织较有力的持续进攻 |
| ≥200/s | 富裕 | 大规模高级部队、昂贵防线，必要时考虑核武器 |

以上不是购买许可或禁令。敌情、现金、生产时间和当前已有单位可能推翻这些建议。

## 3. 矿脉扩张规则

1. **有安全矿脉可拿**：通常优先于单纯囤钱；尽量及早建立可持续收入。
2. **有争夺中的野生矿脉**：评估敌人抢占后是否会形成严重收入差距；必要时派护卫。
3. **地图有陆地不可达矿脉**：考虑海上建造者、跨海运输等特殊路线，不要反复派无法到达的陆军。
4. **矿区不安全**：先判断其防守成本是否小于战略收益，不能为了每座矿不计代价。
5. **已有矿**：稳定时优先考虑升级到 T2/T3。x2+ 对局中稳定控制 2–3 座 T2+ 矿，常能支持小规模进攻。
6. **超频升级**：经济允许时可考虑约 8000 的超频模式；护盾模式通常性价比偏低。

## 4. 没矿可抢时

局势稳定、倍率 x2+ 且缺少可扩张矿脉时，可以使用**资源制造仪**提升收入。

- 通常优先将现有资源制造仪升级 T2/T3，而不是大量铺 T1。
- 若敌军即将进攻，先确保短期战斗力；资源制造仪不能直接阻止攻势。
- 长期对局经济增长没有固定上限，可持续投入。

## 5. 资金使用纪律

- 工厂**下单立刻扣钱**，生产队列不是“未来才需要付钱”。
- 余额过多且无明确用途，通常应投入经济、生产或有效防御。
- 余额较少但马上需要关键升级时，可以主动储备资金。
- 别因为买得起单个高级单位，就忽略其生产时间和后续护卫需求。
- 如果经济扩张会立即丧失重要军事实力，应推迟该投资。
