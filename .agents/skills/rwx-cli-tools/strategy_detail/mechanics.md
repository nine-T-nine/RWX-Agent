# Game Mechanics and Unit Limitations

> This file provides supplementary information. Read it when a mechanic is unclear, when considering an unusual unit, or when planning an expensive strategy. Do not delay urgent actions just to read it.

## 1. Key Mechanics

| Mechanic | Strategic implication |
|---|---|
| Command Center: +18 income, high HP, can attack aircraft, moderate damage but slow firing | Can handle minor harassment alone, but should not be expected to stop swarms or dedicated counters |
| Factory orders deduct credits immediately | Check available balance and urgent expenses before queueing production |
| Shields usually regenerate; electrical damage penetrates shields | Electrical weapons may be valuable against heavily shielded Mechs |
| Many Mechs can cross mountainous terrain | Exploit difficult routes, while respecting artillery and electrical counters |
| Interceptors specialize in anti-air | Use them for mobile air defense, not unrelated frontal ground attacks |
| Turret defenses can reach very high combat effectiveness | Respect fortified positions, but do not automatically spend the entire economy on static defenses |
| RWX often features mass-unit attacks, economic expansion, entrenched turret lines, and nuclear warfare | Adapt to income multiplier, map, and enemy forces instead of using a fixed opening |
| The situation changes quickly | Monitor important outcomes after issuing orders and handle battlefield anomalies promptly |

## 2. Units Often Deprioritized in Human Matches

| Unit | Common assessment | Possible exception |
|---|---|---|
| Basic Helicopter | Rarely used by human players | Has a clear low-cost purpose |
| Bomber | Mostly used late-game against entrenched defenses | Economy is strong and the fixed target is valuable |
| Shielded Hover Tank (experimental, about 21,000) | Too expensive for most normal matches | Extremely wealthy, prolonged game |
| Tesla Mech (T2 Mech Factory) | Often dies too easily | Has a specific electrical-damage target and adequate protection |
| Basic Submarine (about 800) | Relatively fragile and rarely used by humans | Underwater routes offer a clear tactical benefit |

"Rarely used" does not mean "never use." An Agent may find value through superior information or multi-unit control.

## 3. Limits of These Guidelines

- Prices, tech requirements, counters, and popularity are based on practical experience. **Actual game state, mod configuration, and available actions take precedence.**
- "Unit A counters Unit B" does not mean A wins regardless of numbers, position, or timing.
- Heuristics such as "10+ units," "5+ Battleships," or "2–3 deposits" are not strict action thresholds.
- If observed results conflict with these guidelines, trust the observed state and update the plan.
- This file does not specify how an Agent queries state, waits, subscribes to events, or sends commands. Those belong in the communication and tool documentation.
