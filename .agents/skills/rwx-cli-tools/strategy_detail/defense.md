# Defense and Unit Counters

> Read this file when planning defenses, responding to an attack, or preparing counter-artillery / anti-air protection. Prefer using available forces for immediate threats: new turrets and upgrades do not provide firepower until completed.

## 1. Identify the Threat First

| Enemy situation | Defensive focus | Common mistake |
|---|---|---|
| Swarms of low-HP ground units | Flamethrower turrets, area damage, artillery | Building only more basic low-tier turrets |
| Mech assault | Tesla Towers, T2 Tesla Towers, artillery | Ignoring shield penetration and Mechs' mountain mobility |
| Long-range artillery | Laser Defense Turrets, counter-battery fire, repositioning | Keeping dense formations inside enemy artillery range |
| Air raid | T2 anti-air, Anti-Air Mechs, Interceptors | Treating T1 anti-air as a complete defense |
| Massed advanced aircraft | T3 anti-air, Flak Guns, AA Fighters, etc. | Spreading anti-air too thin to destroy targets quickly |

Response order: **identify the threatened assets → deploy existing counters → decide whether to produce units or build turrets → observe the result**. If the defense clearly cannot hold, consider evacuating valuable mobile units and establishing a fallback line.

## 2. Ground Turrets

| Unit / upgrade | Typical use | Limitations |
|---|---|---|
| T2 Machine Gun Turret | General-purpose base defense | Cannot replace all specialized defenses |
| T3 Machine Gun Turret | Wide coverage and rapid fire; one can provide major firepower | About 11,000 credits; generally not an early-game choice |
| Flamethrower Turret | Counters groups of fragile basic Mechs, Tanks, and Hover Tanks | About 500 + 700 credits; short range but relatively high HP |
| Tesla Tower | Effective against Mechs; penetrates shields | Slow attack rate; weak alone against huge swarms |
| T2 Tesla Tower | Very strong counter to advanced Mechs | Expensive; upgrade only when the threat justifies it |
| Artillery Turret | Long-range ground suppression | Upgrade costs about 1,600; usually not a priority early on |
| T2 Artillery Turret | Extremely long range; ideal for positional advances and bombardment | High cost; usually unsuitable early on |

Turrets are important in RWX. A well-developed defensive line can withstand many attacking units, but no single turret type counters everything.

## 3. Anti-Air Options

| Unit / upgrade | Typical use | Cost / limitation |
|---|---|---|
| T1 Anti-Air Turret | Basic point defense | About 600 credits; weak on its own |
| T2 Anti-Air Turret | Preferred standard base anti-air | About 600 + 1,200 credits |
| T3 Anti-Air Turret | High-tier, long-range anti-air | About 12,000 credits; expensive |
| Flak Gun | Strong area damage against aircraft | About 4,000 credits; slightly shorter range |
| Anti-Air Mech | Cost-effective, mobile area anti-air | Moderate HP; useful as an escort |
| Heavy Interceptor | Fast, rapid-firing mobile anti-air | Avoid flying unsupported into enemy anti-air positions |

Do not place expensive anti-air everywhere. Prioritize the Command Center, economy, key factories, and likely attack routes.

## 4. Support Defenses and Defensive Artillery

- **Repair Bay (about 1,500 credits):** Useful for high-HP, high-value units. Try to cover frontline turrets as well. With limited funds, usually build no more than one, and only when units can benefit from repeated repairs.
- **Laser Defense Turret:** Commonly used to intercept enemy artillery and other projectiles. A T2 upgrade costs about 2,000 credits. It is not universal protection against every attack.
- **Heavy Artillery:** Available from a T2 Land Factory, about 2,000+ credits. Useful for long-range defense and stopping ground pushes.
- **Artillery Mech:** Available from a T1 Mech Factory, about 1,700 credits. Useful as mobile artillery, particularly on mountainous maps.

## 5. Defensive Line Principles

1. Protect the **Command Center, main resource areas, and critical production buildings** rather than covering the entire map evenly.
2. Give important turrets overlapping fields of fire; consider repairs and counter-artillery protection.
3. For forward defenses, establish sustainable fire coverage before extending farther. Do not send unprotected Builders deep into enemy positions.
4. If the enemy mainly uses aircraft, reduce spending on irrelevant ground turrets, and vice versa.
5. When battle results show that a defense does not work, change the counters instead of repeatedly rebuilding the same configuration.
