# task-021：CLI 持久通信与低延迟文档

目标：保留原 CLI 协议和调用方式，支持 Agent 可解析的持久通信并对比开销。

改动：`rwx-cli.py --stdio` 逐行接收现有命令语法，逐条输出 UTF-8 JSONL；stderr `ready` 表示握手完成，异常不自动重发。framed 接收改为缓冲处理，旧批量和交互模式共用；START、工具 README 和中英文 help 8.1 更新通信选择及时间含义。新增标准库回归测试和可复现基准 `agent-operation/tools/benchmark-rwx-cli.py`。

验证：完整 `:core:test :desktop:headlessArchive` 成功，26 套件 226 测试全部通过；Python 协议测试覆盖中文、多行、空帧、错误、截断、断连、超时、多实例、逐条 flush、单次及批量兼容。独立 Windows Headless 实例的 Lake (2p) 单机对局暂停在游戏时间 00:16；真实 `--stdio` 连续执行 ping、中文参数查询、多行状态和错误回执，START 的持久 TCP 示例及 README 的单次示例执行通过。内部 tick 仍变化。

同一台机器、同一实例，30 次样本（毫秒；P50 / P95 / 最大值；P95 为最近秩）：

| 测量 | ping | game-state --summary |
|---|---|---|
| Python 单次端到端 | 182.098 / 193.898 / 195.072 | 181.777 / 214.618 / 219.459 |
| Python 持久进程管道至完整回复 | 1.018 / 1.139 / 1.166 | 2.195 / 3.059 / 5.103 |
| 直接持久 TCP 请求至完整回复 | 0.492 / 0.652 / 0.658 | 1.686 / 2.641 / 4.414 |

额外采样：解释器启动并退出 56.140 / 67.305 / 87.989 ms；Python 持久进程启动、端口验证、连接、握手至 ready 168.921 / 187.099 / 212.142 ms；直接 TCP 连接 0.854 / 18.100 / 22.731 ms；单次直接握手 0.339 ms。端到端含游戏处理，不能推导纯引擎执行时间；单次模式未分别埋点测量其连接和处理时间。样本并非跨机器性能保证。复现：启动对局后执行 `python agent-operation/tools/benchmark-rwx-cli.py --port-file <实例端口文件> --count 30`。
