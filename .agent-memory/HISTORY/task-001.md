# task-001（2026-10-24）

## 目标

按用户要求在 Lake (2p)、Impossible、x2 收入打 1v1；随后修复对局中发现的三个问题：
投降指令无效、`restart` 不保留房间设置、新增“智能辅助/反击”自动化（help.md 5.3.10）；
再统一“手动命令优先级最高”的微操让权规则。

## 改动

- 投降：`rwx-game-surrender` 走引擎系统命令（回放可重放），修正把 `isTeamVictory`（实际表示投降）误报为胜利的 CLI 输出；
  投降时先取消自动化与待发指令。
- `restart`：重载前保存/恢复房间设置、出生点、阵营、颜色、AI 难度覆盖，清除上一局投降/战败状态。
- 新增 `assist-counter` 规则：己方单位/建筑在攻击范围内受击且自身 >40% 血量时助攻；自身受击时 ≥40% 反击，
  否则后撤 3 格，脱困后回到空闲；只接管 idle 单位。
- 让权：手动移动/攻击/停止/排队/动作/姿态命令都会撤销旧的微操动作、恢复和脱困指令；重新 `auto-set` 才恢复授权；
  手动生产/取消会暂停旧补产，较新的替换任务清除冲突待发指令。
